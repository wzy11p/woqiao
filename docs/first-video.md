# 制作第一条短片

目标：先完成一条可导出的三镜头短片，再扩展到多人物漫剧。

## 1. 准备素材

- 一张轮廓清楚的人物图。动作镜头优先使用全身图，并统一发型、服装和画风。
- 可选场景图、动作参考视频、参考音乐。
- 可选已生成的视频、台词录音与最终配乐。只有照片时，可以先生成动作视频。

上传你有权使用的素材。调用模型时，选定的参考素材会发送给对应云端服务商。

## 2. 建立项目与镜头

进入「人物与动作」，新建项目，选择 16:9、9:16 或 1:1。先添加三个镜头，例如「人物进入场景」「停下观察」「跳一个短动作」，每镜只安排一个主要动作。

输入镜头内容与想法。此处的文字用于你后续创作和逐镜生成，当前不会自动替你完成整部剧的导演决策。

## 3. 先稳定镜头图

在每个镜头上传同一张人物参考图，可再加入场景图；选择运镜预设，生成镜头图。检查脸、发型、服装与构图，满意后选用；也可以直接上传外部制作的镜头图。

底层使用参考图编辑/生成接口。每次都沿用同一个角色来源，比只在提示词里反复写人物名字更可控，但不能保证身份完全一致。

## 4. 生成短动作

选择账号实际可用的 Seedance 模型，先尝试约 5 秒。动作参考视频用于约束动作；人物图负责身份外观，场景图负责环境与画风。

如果希望舞蹈动作接近某段音乐的节奏，先上传参考音乐，再在这一镜启用节奏参考并选好起点。参考片段必须覆盖要求的时长。不需要时可以完全不传音乐。

生成后检查角色、手脚、动作完成度与镜头稳定性。可以多生成候选后挑选；每次重新生成可能产生新的 API 费用。有已保存云端任务 ID 的中断任务，可使用继续查询，避免主动重新提交。

## 5. 用剪辑安排节奏

每镜选定一个视频；生成效果不合适时，也可以导入外部视频。调整镜头顺序、裁切起点和保留长度，必要时使用 0.5–2 倍变速。

进入「配乐与剪辑」，导入最终配乐，试听并手工标记需要切镜的位置。界面可以按标记调整镜头长度。实际动作重音若与音乐差距太大，优先重生成或换片段，过度变速会让动作失真。

参考音乐与最终配乐不必是同一文件。换音乐后，应重新检查节奏关系。

## 6. 添加台词并导出

给需要说话的镜头上传音频，设置出现时间，调整原声音量与配乐音量。当前没有口型同步或声音克隆保证。

确认每镜都选定有效视频，再导出。后端会用本地 FFmpeg 裁切、变速、拼接与混音，生成 MP4。横屏为 1280×720，竖屏为 720×1280，方形为 720×720，24 fps。

导出后完整看一遍：有没有漏镜、角色跳变、音画错位、音量突变。先把这条短片做顺，再增加镜头和角色。
