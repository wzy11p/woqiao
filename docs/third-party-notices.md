## 本仓库的主要调整

- 卧巧中文品牌与已选定的黑色眠鸟 Logo。
- 逐镜人物/场景参考、动作视频、可选节奏音频与候选管理工作台。
- GPT Image 参考图编辑路径、Seedance 多模态请求和云端任务 ID 恢复查询。
- 项目持久化、上传素材留存，以及 FFmpeg 裁切、变速、台词/配乐混合与导出。
- 配置脱敏、媒体路径约束、回归测试及发布文档。
